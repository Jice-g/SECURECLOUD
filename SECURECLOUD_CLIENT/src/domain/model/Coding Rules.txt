

namespace domain :
All Domain code lives in namespace domain.
Prevents name collisions with Qt, STL, or third-party libraries.

enum class :
Scoped, type-safe. Values must be written UserRole::ADMIN, never ADMIN.

///< Doxygen comment :
Documents each enum value inline. Generated documentation tools will pick this up.
/// Above declaration : Full Doxygen comment for the enum itself.

int underlying type : Default int is fine. If we later need compact storage (SQLite serialization), we can add : std::uint8_t.
For an int, in general : Use size_t, uint8_t, unint16_t, uint64_t, instead.

Header Only : No .cpp file ; There is no code to compile. Enums are pure declarations.
